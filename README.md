# Generador de Moda IA - MVP

Proyecto Next.js listo para importar en Vercel.

## Qué funciona ahora
- Formulario de 5 pasos
- Carga y vista previa de una foto
- Opciones de modelo, escenario, cámara y pose
- Pantalla de resultado demo
- Pantalla demo de generador de video

## Qué falta
- Conectar una API real de generación de imágenes
- Conectar una API real de video
- Usuarios, créditos y pagos

## Ejecutar localmente
npm install
npm run dev
